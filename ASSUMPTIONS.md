# Assumptions

## Header controls

The header keeps Settings, Refresh and one theme toggle.

Settings and Refresh are required controls. The Main reference shows neither. Each control is a 36px icon button with an 8px gap. The search box keeps its width. The two controls move the search start from x1038 to x1002.

Refresh stays on the overview. It asks the app to poll again. The Needs you page has no refresh control.
